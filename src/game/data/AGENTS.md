# data

## Purpose
Static game data and its accessors: monster tiers, skill definitions, and the generated tree-node JSON. `monsters.json` / `treeNodes.json` are generated by `scripts/extract-xlsx.mjs` from the spreadsheets in `docs/` — do not hand-edit them; regenerate instead.

## Key Files
| File | Description |
|------|-------------|
| `monsters.json` | **Generated.** 22-tier monster stats, produced by `npm run extract-xlsx` from `docs/arcane_shell_monster_stats.xlsx` |
| `monsters.ts` | Accessor layer over `monsters.json`: `getMonster(tier)`, `spawnMonster(tier)` (fresh `MonsterInstance` at full HP), `rollDrop(instance)` (deterministic midpoint of the drop range — master_spec.md §2-2: no probability roll), `MAX_TIER_MILESTONE_1` (= 5, current unlock ceiling) |
| `treeNodes.json` | **Generated.** 55-depth tree cost data, produced by `npm run extract-xlsx` from `docs/arcane_shell_tree_node_cost.xlsx` |
| `skills.ts` | Hand-authored (not generated) skill definitions: 6 grade-1 deal skills (one per element, `${elementEn}_1`) + 3 buff skills (haste/focus/overload), per `content_design.md` §1 and `master_spec.md` §5-1. `getSkill(id)`, `getDealSkills()`, `getBuffSkills()`, `dealSkillForElement(element)`. |

## For AI Agents

### Working In This Directory
- Never hand-edit `monsters.json` or `treeNodes.json` — edit the source `.xlsx` in `docs/` and re-run `npm run extract-xlsx` (see `scripts/AGENTS.md`).
- `skills.ts` is the one file here that's hand-authored game data (not spreadsheet-derived) — new skills/grades go here, following the existing coefficient/mana-cost citation comments back to `content_design.md` / `master_spec.md`.
- `MAX_TIER_MILESTONE_1` and tree depth 1-10 unlock ceilings (in `stores/useTreeStore.ts`) are the current milestone's scope gates — raising them is a deliberate content-unlock decision, not a bug fix.

### Testing Requirements
- Indirectly covered by `game/formulas/formulas.test.ts` (tree cost curve cross-checked against `treeNodes.json`) and `game/integration.test.ts` (spawn/kill/drop flow). No dedicated data test file.

### Common Patterns
- Each data module exports both the raw typed array and a `Map`-backed lookup-by-key function for O(1) access (`BY_TIER`, `NODE_BY_DEPTH`, `SKILL_BY_ID`).

## Dependencies

### Internal
- `../../types/Monster.ts`, `../../types/TreeNode.ts`, `../../types/Skill.ts`, `../../types/Element.ts`, `../formulas/manaUptime.ts` (mana cost % constant)
- Source of truth: `docs/arcane_shell_monster_stats.xlsx`, `docs/arcane_shell_tree_node_cost.xlsx` (via `scripts/extract-xlsx.mjs`)
