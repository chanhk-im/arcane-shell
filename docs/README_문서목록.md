## 읽는 순서

| ③ | `arcane_shell_content_design.md` | 9개 콘텐츠(몬스터도감~재귀컴파일) 개별 상세 설계 |

## 핵심 확정 수치 (한눈에)

- **환생 없음** (랭크10 이후 별도 확장에서 검토 예정)
- **총 플레이타임**: 랭크0~10 약 278시간 (11.6일)
- **랭크1~3**: 2~2.5시간대로 빠르게, 이후 점진 감속
- **마석 5등급 / 몬스터 22티어 / 트리 55깊이 10랭크 / 스킬 30개(6속성×5등급) / 유물 5종(보스 5마리 매칭)**

## 문서 간 의존 관계

```
master_spec (총괄)
 ├─ play_flow ─────────┐
 ├─ content_design ─────┼─ 서로 참조, 콘텐츠 배치 근거
 ├─ stats_summary ──────┤
 └─ script_api ─────────┘
        │
        ▼ (수치 검증은 전부 스프레드시트가 원본)
 monster_stats.xlsx → tree_node_cost.xlsx → dps_model.xlsx
```

스프레드시트 3개는 서로 참조하는 값이 있지만(예: DPS 모델의 "참조데이터" 시트는 몬스터 스탯·트리 비용에서 계산된 값을 반영해 넣은 것) 라이브 링크는 아닙니다. **한쪽을 고치면 다른 쪽도 수동으로 다시 맞춰야 합니다** — 이 부분은 개발 착수 전 실제 데이터 파이프라인(JSON/DB 등)으로 옮기면서 자동 동기화되게 설계하는 걸 권장합니다.

## 개발 착수 시 우선 확인할 것

1. `master_spec.md` 10절의 "범위 밖으로 이관된 항목"부터 확인 — 미완성 부분 명확히 인지
2. 스프레드시트 값이 "첫 시안"이라는 점 — 실제 플레이테스트 없이 나온 수치이므로 프로토타입 이후 조정 전제
3. `script_api.md`의 "새로 남은 것" 항목(타겟 목록 상한 등) — 엔진 구현 시 결정 필요
