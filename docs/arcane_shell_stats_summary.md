# Arcane Shell — 능력치 & 능력치 증가 정리 (v1)

## 1. 5대 기본 스탯

| 스탯 | 효과 |
|---|---|
| 주문력 | 주문 피해량 증가 (히트당 데미지에 직접 곱연산) |
| 민첩 | 명중률 + 크리티컬 확률 + 공격속도(쿨감)에 영향 |
| 마나 | 최대 마나량 (마나풀 크기) |
| 마나회복 | 마나 재생 속도 |
| 지능 | 주문력·마나·마나회복에 배율로 증폭 (간접 핵심 스탯) |

**적용 공식**
- 지능배율 = `1 + 지능/100` (상한 없이 계속 커짐 — 방치형 장르 후반 폭발 성장 담당)
- 명중률 = `90% + 9%×(민첩/(민첩+200))` (상한 99%로 수렴)
- 크리확률 = `5% + 75%×(민첩/(민첩+300))` (상한 80%로 수렴)
- 공격속도배율 = `1 + 2×(민첩/(민첩+400))` (상한 3배로 수렴)

명중률·크리확률·공격속도는 스탯이 무한히 커져도 특정 상한에 수렴하는 점감형 공식, 주문력·지능은 상한 없이 곱연산으로 계속 커지는 쪽 — 두 계열을 의도적으로 다르게 설계했습니다.

## 2. 파생 스탯 (전용 소스 필요, 트리에는 노드 없음)

| 스탯 | 기본값(룬 없음) | 획득 수단 |
|---|---|---|
| 크리티컬 피해 | 150% | **룬 각인 전용** (랭크6+) |
| 방어 관통 | 0% | **룬 각인 전용** (랭크6+) |

이 둘은 "이후 컨텐츠 핵심 스탯"으로 처음부터 룬 전용으로 설계했습니다 — 랭크6 이전엔 존재하지 않다가, 룬 각인 언락과 동시에 등장.

## 3. 스탯 증가 수단 4가지

### 3-1. 아르카나 트리 (모든 랭크, 주 성장 경로)
- 55깊이 그래프, 5스탯에 균등 분배(각 1/5)
- `스탯증가량 = 깊이당노드수(6) × k(0.0252) × 1강비용 × 1/5`
- 1강비용 자체가 깊이·등급별로 톱니 곡선(등급 전환마다 리셋 후 재성장)이라, 스탯도 같은 리듬으로 증가
- **k값은 이 문서 작성 시점까지 여러 차례 재조정됨**: 0.1 → 0.05 → 0.0275(스킬계수 반영) → 0.0335(마나 가동률 반영) → 0.0318(마나 %化 반영) → **0.0252(부품·룬 통합 반영, 최종)**

### 3-2. 부품 (CPU/GPU/HDD/RAM/메인보드)
| 부품 | 주 스탯 | 보조 옵션 (등급에만 비례, 강화 무관) |
|---|---|---|
| CPU | 주문력 | 세계 속도 증가 |
| GPU | 민첩 | 히트수 기댓값 증가 (동일 타겟 추가 히트, 확률형) |
| HDD | 마나 | 저장 용량 |
| RAM | 마나회복 | 메모리 용량 (스크립트 동시 실행) |
| 메인보드 | 지능 | 타 부품 보조옵션 증폭 |

- 등급별 기본치(1강): 10 / 25 / 60 / 150 / 375 (등급마다 2.5배)
- 강화: 1~25강, 강화당 8% 복리 (25강 만강 시 기본치의 약 6.34배)
- 계승: 8강 이상만 가능, 이전 시 -8강 페널티
- **DPS 모델 반영**: 등급 첫 랭크는 8강, 둘째 랭크는 20강 가정으로 계산 — 랭크1에서 부품 스탯(17.1)이 트리 스탯(21.1)과 맞먹을 정도로 초반 비중이 크고, 후반으로 갈수록 트리가 압도

### 3-3. 룬 각인 (랭크6+, 부품당 소켓 1개)
- 5희귀도, 룬당 3~5옵션(희귀도 높을수록 5쪽에 가까움)
- 옵션 풀: 기존 5스탯(+N/+N%) + 크리피해·방어관통·명중률 + 마석/골드/명성 획득량 + 스크립트메모리·부품강화확률
- 옵션마다 별도 "옵션 등급"(5단계) 존재 — 룬 희귀도가 높을수록 고옵션등급 확률↑ (낮은 희귀도에서도 로또처럼 최고등급 가능)
- 리롤 3회(골드, 비용 급상승) + 합성(동일 룬 3개→같은 희귀도 재추첨)
- **DPS 모델 반영**: 희귀도별 기댓값 4.2%(희귀도1) ~ 14.3%(희귀도5), 랭크6→10에 걸쳐 5.0%→12.8%로 접근 가능 희귀도가 높아진다고 가정

### 3-4. 몬스터 도감 (랭크2, 마석 소모 없는 유일한 성장 경로)
- 속성별(화/수/뇌/지/성/암, 6종) 누적 처치 트래킹
- 속성당 500마리 누적 시 만렙, 최대 +15% (해당 속성 데미지)
- 100마리당 +3%씩 선형 비례
- 모든 속성을 고르게 채우기보다 자주 잡는 속성 위주로 자연히 편중되는 설계

## 4. 스킬 계수

- 6속성(화/수/뇌/지/성/암) × 5등급 = **총 30개 스킬**
- 등급 전환과 동시에 그 등급 6개 세트 한번에 해금
- 계수 성장률: **등급당 50% 복리** (1.0 → 1.5 → 2.25 → 3.375 → 5.0625)

## 5. 마나 시스템 (스탯 무관 영구 관련성 설계)

- 스킬 마나소모 = **최대마나 대비 5%/회** (고정값 아님 — 스탯 크기와 무관하게 항상 %)
- 마나회복 = **최대마나 대비 10%/초**
- 가동률 = `MIN(1, 10% ÷ (5%×공격속도배율))`
- 공격속도가 상한(3배)에 가까워질수록 가동률이 낮아지다가, **67~70%에서 영원히 고정** — 마나/마나회복 스탯이 게임 끝까지 죽지 않는 핵심 장치

## 6. 최종 스탯 합성 공식

```
최종 스탯 = (트리 스탯 + 부품 스탯) × (1 + 룬 기댓값)
```

## 8. 아직 스탯 시스템에 남은 미해결 사항

1. **히트수 기댓값(GPU 보조옵션)이 DPS 모델에 아직 미반영** — 현재 1.0(효과 없음) 고정값으로 계산 중
2. **6속성 스킬 간 마나소모 차등 여부** — 현재는 속성 무관 전부 동일
3. **버프 스킬(가속/집중/과부하 등)의 구체 수치** — 방향만 논의, 수치 미확정
4. **몬스터 도감 보너스가 DPS 모델에 정량 반영 안 됨** — 정성적 설계만 있음
5. **환생 시스템: 확정적으로 배제** (재귀 컴파일 = 신규 트리 브랜치로 대체, 능력치 초기화 루프 없음)
