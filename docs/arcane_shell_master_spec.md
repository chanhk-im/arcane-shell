## 2. 몬스터 & 전투 시스템

### 2-1. 몬스터 티어 (22단계)
- HP 곡선: 4구간 가속 (초반1-6: 50%/티어, 중반7-12: 100%, 후반13-17: 175%, 엔드18-22: 300%)
- 방어력 곡선: 4구간 (10%/15%/20%/25%) — **재조율 검토했으나 유지 결정** (HP만큼 가파를 필요 없음, `100/(100+방어력-방어관통)` 감쇠식이 이미 완만한 곡선을 만들어줌)
- **보스 = 각 마석등급의 마지막 티어(5/10/14/18/22)로 확정** — 기존 "5티어마다"였던 주기와 등급 경계가 어긋나던 문제 해결

### 2-2. 마석 등급 & 드랍
- 5등급, 몬스터 티어 1-5/6-10/11-14/15-18/19-22에 매핑
- 드랍은 확률 없이 [최소~최대] 수량 직접 결정 (최소=0 고정)
- 등급 전환 직후 최대 2개로 리셋 → 등급 마지막 티어에서 최대치까지 선형 증가
- 등급별 최대치 자체도 80%→**50%** 복리로 커짐(등급1=10 → 등급5=105)
- 보스는 그 등급 최대치를 보장(최소) + 3배(최대)

### 2-3. 속성 상성
- 4원소 순환: 화→수→뇌→지→화 (이기면 +25%, 지면 -25%)
- 대립 2속성: 성↔암 (서로 공격 시 항상 +25%, 양방향)
- 스킬은 등급마다 6속성 각 1개씩 지급 (아래 5절)

### 2-4. 전투 판정 흐름
```
시전 → 명중 판정(민첩) → 크리 판정(민첩) → 데미지 계산(주문력+지능+크리피해) → 방어감쇠(방어력-방어관통) → 속성 보정
```
- 일방적 딜링(몬스터 반격 없음)
- GPU 보조옵션(히트수 기댓값)으로 동일 타겟 추가 히트 가능, 크리 등은 히트마다 독립 판정

## 4. 능력치 & 능력치 증가

(상세는 별도 문서 `arcane_shell_stats_summary.md` 참조. 여기선 이번에 새로 결정된 것만)

- **GPU 히트수 기댓값 반영 확정**: `1 + 0.02 × GPU강화레벨` (8강=1.16, 20강=1.40) — DPS 모델에 통합 완료
- **6속성 간 마나소모 차등: 없음으로 결정** (전부 동일, 단순함 유지)
- **몬스터 도감 보너스**: 정성적 설계만 유지, DPS 모델 정량 미반영(작은 영향으로 판단, 필요시 후속 반영)

## 5. 스킬 & 마나

- 6속성 × 5등급 = 30개 스킬, 등급 전환마다 세트 해금
- 스킬 계수: 등급당 50% 복리 (1.0 → 5.06)
- 마나소모 5%(최대마나 대비/회), 마나회복 10%(최대마나 대비/초) — 가동률이 후반 67~70%에서 영구 고정, 마나회복 스탯이 끝까지 유효

### 5-1. 버프 스킬 (신규 확정)
딜 스킬과 별개 슬롯, 마나 경제 재사용, 지속시간 < 쿨타임으로 상시 유지 불가:

| 버프 | 효과 | 지속/쿨타임 | 마나소모 |
|---|---|---|---|
| 가속 | 공격속도 +30% | 10초/30초 | 5%(일반 스킬과 동일) |
| 집중 | 크리확률 +20%p | 10초/30초 | 5% |
| 과부하 | 주문력 +50%, **마나소모율 +5%p(10%로 증가)** | 8초/40초 | 8% |

과부하는 하이리스크형 — "지금 마나 넉넉하니 몰아친다"는 스크립트 판단을 유도하는 설계.

## 6. 부품 & 룬

### 6-1. 부품
- 등급별 기본치(1강): 10/25/60/150/375 (2.5배씩), 강화당 8% 복리, 25강 만강
- 계승: 8강 이상만 가능, -8강 페널티

### 6-2. 룬 각인
- 부품당 소켓 1개, 5희귀도, 3~5옵션
- 옵션 등급별 확률분포·기댓값(4.2%~14.3%) 확정, 리롤 3회+합성(3개→재추첨)

### 6-3. 유물 (신규 확정)
보스가 이제 정확히 5마리(등급당 1마리)이므로, **유물도 5종으로 확정**:

| 유물 | 출처 | 효과 |
|---|---|---|
| 유물1 | 티어5 보스 | 화속성 데미지 +10% |
| 유물2 | 티어10 보스 | 스크립트 메모리 용량 +20% |
| 유물3 | 티어14 보스 | 크리티컬 피해 +15%p |
| 유물4 | 티어18 보스 | 방어 관통 +10%p |
| 유물5 | 티어22 보스 | 전체 데미지 +15% |

- 6번째 장비 슬롯, 5개 중 1개만 장착
- **강화 가능 확정**: 최대 10강, 강화당 20% 복리, 골드 소비(보스재화 아님 — 재료 소모처를 분산)

## 7. 스크립트 시스템 (자동화 — 신규 상세 설계)

### 7-1. 실행 모델
- JS 서브셋 문법
- 동시 실행 무제한, 대신 **메모리 용량** 병목 (RAM 부품 + 유물2 + 룬 옵션으로 확장)
- 에러 발생 시 해당 스크립트 즉시 종료(추가 페널티 없음)
- 오프라인 시간은 별도 계산식으로 일괄 정산

### 7-2. API 레퍼런스 (1차 확정)

| 함수/객체 | 설명 |
|---|---|
| `cast(스킬명, 타겟?)` | 스킬 시전. 타겟 생략 시 현재 타겟 |
| `target.current` | 현재 타겟 정보(속성, HP%, 방어력) 조회 |
| `target.set(선택자)` | 타겟 변경 (예: `"weakest"`, `"element:화"`) |
| `mana.current`, `mana.max` | 마나 조회 |
| `hp.current`, `hp.max` | (플레이어 없음 — 몬스터 대상 조회용, 필요시) |
| `resource.get(종류)` | 마석/골드/명성 등 보유량 조회 |
| `sleep(ms)` | 대기 |
| `log(msg)` | 콘솔 출력(디버그용) |

`"api"`가 명시된 시스템만 스크립트에서 접근 가능이라는 원칙 유지 — 현재 열린 것: 전투 API, 자원 조회 API. 향후 콘텐츠 추가 시 동일 원칙으로 확장.

### 7-3. 예시 스크립트

```js
// 기본 속성 대응 자동 사냥 스크립트
while (true) {
  const enemy = target.current;
  const bestSkill = pickSkillByElement(enemy.element); // 상성 유리한 속성 스킬 선택
  if (mana.current >= mana.max * 0.5) {
    cast(bestSkill);
  } else {
    // 마나 부족 시 딜 스킬 대신 대기 (또는 향후 버프 스킬 활용 가능)
    sleep(500);
  }
}

function pickSkillByElement(elem) {
  const advantage = { "화": "수", "수": "뇌", "뇌": "지", "지": "화" };
  return advantage[elem] ? `${advantage[elem]}_skill` : "neutral_skill";
}
```

- 이 예시는 "몬스터 속성 감지 → 유리한 속성 스킬 자동 선택"이라는 초기 설계 목표를 그대로 구현
- 매크로(AI 도제, 랭크7+)는 이런 스크립트 여러 개를 하나로 묶어 동시 실행하는 상위 레이어

### 7-4. AI 도제 매크로 세부 (신규 확정)
- 매크로 슬롯: 랭크7 해금 시 2개, 랭크8 완료 시 4개
- 슬롯 1개당 메모리 요구량: 개별 스크립트 평균 요구량의 **1.2배** (묶음 오버헤드)
- 메모리 시스템 자체는 RAM 부품 스탯 + 룬 옵션 + 유물2로 확장 가능

## 8. 콘텐츠 상세 확정 (남은 항목 전부 결정)

### 8-1. 몬스터 도감
속성별(6종) 누적처치 500마리당 만렙, 최대 +15%, 100마리당 +3%.

### 8-2. 차원 균열
등급2부터 1개씩 추가(등급5까지 최대 4개+기본1=5개). 균열 몬스터 등급 = 현재 접근 가능한 최고 등급과 동일(별도 최적화 요소 없음).

### 8-3. 경매장
환율: 등급g 마석 1개 = g×10골드. 상위 등급 마석 구매는 불가.

### 8-4. 길드 레이드 (신규 확정)
- 협동 70%(길드 주간 목표: 보스 처치량 합산 100회 달성 시 전원 보상) + 경쟁 30%(개인 기여도 상위 10% 보너스 1.5배)
- 보상은 골드/명성 위주, 마석 경제 비개입

### 8-5. 차원 심층
등급5 전용 엔드 레이드. "50배" 자동화 배율은 개인차가 큰 대표값(고정 수치 아님) — 자동화 투자(메모리+매크로) 수준에 비례.

### 8-6. 오프라인 보상 (신규 확정)
- 오프라인 동안 마지막 활성 스크립트가 계속 실행됐다고 가정
- 오프라인 처치 속도 = 온라인 대비 **70%** (자원 소모 정밀 시뮬레이션 생략, 단순화)
- 최대 적립 시간 **24시간** 상한 (그 이상은 적립 안 됨 — 재접속 유도)

### 8-7. 재귀 컴파일 (랭크10, 확정)
- **환생 시스템 아님.** 신규 아르카나 트리 브랜치를 여는 확장 게이트로 정의
- **향후 계획**: 랭크10 완주 후 추가되는 확장 콘텐츠에서 환생류 시스템(가칭)을 별도로 설계 예정 — 이번 명세서 범위 밖으로 명시적 이관

## 10. 정말로 남은 것 (범위 밖으로 명시적 이관)

1. **재귀 컴파일 이후의 신규 트리 브랜치 + 환생류 시스템** — 다음 설계 세션
2. **몬스터 도감 보너스의 DPS 모델 정량 반영** — 영향 작다고 판단해 이번엔 생략, 필요시 추가
