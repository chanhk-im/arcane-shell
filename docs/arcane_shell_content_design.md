# Arcane Shell — 스킬 티어 & 잔여 콘텐츠 설계 (v1)

## 1. 스킬 시스템

### 구조
- **속성 6종**: 화/수/뇌/지 (4원소 순환) + 성/암 (대립 2종)
- **스킬 등급 5단계**: 마석 등급과 1:1 매칭 (등급1~5)
- **등급당 속성별 1개씩 = 6개**, 총 **5등급 × 6속성 = 30개 스킬**

### 해금 시점
등급 전환과 동시에 그 등급의 6개 스킬 세트가 한 번에 열립니다.

| 스킬 등급 | 해금 랭크 | 대응 마석 등급 |
|---|---|---|
| 1 | 랭크1 (시작) | 등급1 |
| 2 | 랭크3 | 등급2 |
| 3 | 랭크5 | 등급3 |
| 4 | 랭크7 | 등급4 |
| 5 | 랭크9 | 등급5 |

### 스킬 계수 (주문력 배율)
DPS 모델에서 지금까지 스킬계수를 1.0 고정으로 뒀는데, 이제 등급별로 분리합니다.

**계수 성장률: 등급당 50% 복리** (드랍 성장 곡선과 같은 리듬으로 맞춤 — 새 등급 스킬을 처음 배우는 순간 확실한 체감 상승을 주기 위함)

| 스킬 등급 | 계수 |
|---|---|
| 1 | 1.00 |
| 2 | 1.50 |
| 3 | 2.25 |
| 4 | 3.38 |
| 5 | 5.06 |

같은 등급 안의 6개 스킬(화/수/뇌/지/성/암)은 계수가 전부 동일하고, 속성 상성(±25%)으로만 차등을 둡니다. **스크립트 확장 계획**(예전 설계에서 언급된 "몬스터 속성 감지해서 자동으로 대응 스펠 선택")이 이 6개 세트를 순환시키는 방식으로 자연스럽게 이어집니다.

### 스킬 명명 예시 (컨셉: 마법=코드/인프라)
| 속성 | 스킬명(예시) |
|---|---|
| 화 | `ignite()` |
| 수 | `flush()` |
| 뇌 | `interrupt()` |
| 지 | `commit()` |
| 성 | `patch()` |
| 암 | `exploit()` |

이름은 나중에 다듬어도 되지만, "명령어처럼 보이는 스킬명"이라는 톤만 유지하면 세계관과 계속 붙어있을 것 같아요.

### DPS 모델과의 연결
기존 DPS 모델 가정 시트의 `스킬 계수 = 1.0` 고정값을, 랭크별로 해당 스킬 등급의 계수를 대입하도록 바꿔야 합니다 (랭크1~2는 1.0, 랭크3~4는 1.5, ... 랭크9~10은 5.06). 이러면 DPS가 지금 계산보다 등급마다 최대 5배 더 강해지므로, 지난번 튜닝한 자동화 배율(3x, 50x)이 다소 과할 수 있습니다 — **이 부분은 실제로 반영한 뒤 재검산이 필요합니다.**

## 2. 잔여 콘텐츠 설계

### 2-1. 몬스터 도감 (랭크2)

| 항목 | 내용 |
|---|---|
| 트리거 | **속성별** 누적 처치 수 (몬스터 티어가 아니라 몬스터의 속성으로 집계) |
| 보상 | 해당 속성 데미지 영구 % 증가, 속성당 500마리 누적 시 만렙 |
| 수치 | 6개 속성 트랙 각각 최대 **+15%**, 500마리에 걸쳐 선형 비례 (100마리당 +3%) |
| 목적 | 마석 소모 없이 얻는 유일한 영구 성장 레이어 |

전체 6속성을 다 채우면 이론상 데미지 +15%×6=+90%가 아니라, **자신이 자주 잡는 속성 위주로 자연히 편중**되도록 설계된 겁니다(모든 속성을 500마리씩 골고루 잡을 이유가 없음) — 실제로는 플레이어가 주력으로 삼는 1~2개 속성만 만렙 찍고 나머지는 낮은 단계로 남는 그림이 자연스럽습니다.

### 2-2. 차원 균열 (필드 확장, 랭크3)

| 항목 | 내용 |
|---|---|
| 메커니즘 | 기존 사냥터와 별개로 열리는 병렬 사냥터. 스크립트를 균열마다 독립 배치 |
| 균열 개수 | 등급별로 1개씩 추가 해금 (등급2 시작 시 1개 → 등급5까지 총 4개 균열 + 기본 사냥터 = 최대 5곳) |
| **균열별 마석 등급** | **항상 "현재 접근 가능한 최고 등급"과 동일** — 별도 최적화 요소를 만들지 않고, 순수하게 처리량 배수 역할만 담당 (단순함 유지) |
| 밸런스 포지셔닝 | 등급1~3 자동화 배율(1x 고정)은 "균열 없이 단일 사냥터만 쓴다"는 보수적 가정이고, 균열을 실제로 활용하면 그보다 빠를 수 있음 — 즉 균열은 **여유 마진**으로 존재 |

### 2-3. 경매장 / 마석 거래소 (랭크4)

| 항목 | 내용 |
|---|---|
| 기능 | 하위 등급 잉여 마석 → 골드 환전 (상위 등급 마석 구매 불가) |
| **환율** | 등급g 마석 1개 = **g × 10 골드** (등급1=10골드 … 등급5=50골드) — 트리 비용 곡선의 등급별 시작값(10/20/30/40/50)과 동일한 선형 체계로 통일 |
| 목적 | 효율 낮은 하위 등급 마석 재고 처리, 골드는 유물 강화·길드 의뢰 등에서 소비 |

### 2-4. 유물 시스템 (랭크5)

| 항목 | 내용 |
|---|---|
| 슬롯 | 부품 5종과 별개인 6번째 장비 슬롯 |
| 재화 | 보스 고유 재화 전용 소비처 |
| 효과 | 보스별 고정 단일 효과 (드랍 랜덤 없음 — "이 보스를 왜 잡았는지"가 명확하도록) |
| **강화 여부** | **강화 가능**, 최대 **10강** (부품·룬보다 낮은 상한 — 유물은 고정효과+수치만 키우는 심플한 라인), 강화당 20% 복리, 골드 소비 |

### 2-7. 길드 레이드 / 리더보드 (랭크8)

| 항목 | 내용 |
|---|---|
| **비중** | **협동 70% + 경쟁 30%** — 길드 단위 주간 목표(보스 처치량 합산, 협동) + 개인 기여도 리더보드(보상 차등, 경쟁) 혼합 |
| 보상 | 골드/명성 위주, 마석 경제에는 개입하지 않음 (지금까지 맞춘 마석 밸런스 보호) |

### 2-8. 차원 심층 (엔드 레이드, 랭크9)

| 항목 | 내용 |
|---|---|
| **50배 메커니즘** | 차원 균열이 "고정 슬롯(등급당 1개)"이었다면, 차원 심층은 **자동화 투자(메모리 용량 + 매크로 슬롯)가 허용하는 한 인스턴스를 계속 늘릴 수 있는 개방형 구조** — 즉 50배는 고정 수치가 아니라 "랭크9~10 시점 평균적인 자동화 투자 기준"의 대표값 |
| 함의 | 실제 배율은 플레이어의 스크립트/매크로 투자 수준에 따라 개인차가 커짐 — 밸런스상 50배는 "중간값 플레이어" 기준선으로 유지 |

### 2-9. 재귀 컴파일 (랭크10)

| 항목 | 내용 |
|---|---|
| **방향 결정** | **옵션 C 채택** — 환생 대신 완전히 새로운 진행축(신규 아르카나 트리 브랜치, "확장팩" 개념) 해금 |
| 근거 | 예전에 명확히 결정했던 "레벨/cron/환생 폐지" 방향을 그대로 존중. "재귀 컴파일"이라는 이름은 유지하되, 기존 자원을 리셋하는 대신 완전히 새로운 콘텐츠 레이어를 여는 열쇠로 재정의 |
| 확인 필요 | 신규 트리 브랜치의 구체적 내용은 별도 설계 세션 필요 (지금 범위 밖) |
